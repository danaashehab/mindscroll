# Curiosity Learning Platform

> A personalized curiosity engine that transforms scrolling into
> meaningful learning.

## Vision

The Curiosity Learning Platform is built around a simple belief:

**Scrolling can become one of the best ways to learn instead of one of
the biggest distractions.**

Rather than presenting isolated trivia, every card introduces an idea,
mental model, discovery, historical insight, or perspective that
encourages users to understand themselves and the world more deeply.

## Core Experience

-   One idea per vertical scroll
-   Minimalist interface
-   Progressive depth
-   Personalized recommendations
-   AI learning companion
-   Curated learning resources

## Navigation

  -----------------------------------------------------------------------
  Action                              Purpose
  ----------------------------------- -----------------------------------
  Vertical Swipe                      Discover a new idea

  Right Swipe                         Read a curated expansion of the
                                      same idea and access articles, TED
                                      Talks, books and videos

  Left Swipe                          Ask the AI questions about the
                                      current idea

  Like                                Improve future recommendations

  Profile                             Settings, history, liked ideas, AI
                                      conversations
  -----------------------------------------------------------------------

## Content Philosophy

Content should prioritize: - Perspective shifts - Mental models -
Scientific discoveries - Human behaviour - Hidden systems - Thought
experiments - Philosophy - History - Astronomy - Technology - Islam
(trusted sources)

## Recommendation Philosophy

-   70% personalized learning
-   30% discovery outside current interests

The goal is to broaden thinking rather than trap users in a filter
bubble.

## Long-Term Goal

Build a lifelong curiosity companion that helps people become more
thoughtful, knowledgeable and intellectually confident.
